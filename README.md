# Corporate Valuation Vault (FMVA®)

## 📌 Project Overview
A collection of professional-grade valuation models covering fictional startups and real-world titans. Built with FMVA® standards to assess intrinsic value, capital structure, and investment risk.

## 🛠 Features
* **3-Statement Modeling:** Fully integrated Income Statement, Balance Sheet, and Cash Flow.
* **DCF Analysis:** Multi-stage Discounted Cash Flow models with terminal value calculations.
* **Comps & Precedents:** Relative valuation using industry-specific EV/EBITDA and P/E multiples.

## 📊 Advanced Analytics
* **Sensitivity Analysis (Data Tables):** Two-dimensional tables testing the impact of WACC vs. Terminal Growth Rates on the final Enterprise Value.
* **Scenario Analysis:** Dynamic "Bull / Base / Bear" switching logic to model operational shifts (e.g., ±500bps in Revenue Growth or EBITDA Margin).
* **Monte Carlo Simulation:** Python-driven probability distribution of price targets based on variable uncertainty.

## 🚀 Impact
Provides a rigorous "Buy/Sell/Hold" thesis by quantifying the margin of safety and identifying the key drivers of value creation.
